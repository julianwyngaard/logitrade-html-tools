tools.julianwyngaard.dev

A collection of single-file HTML tools. Each tool runs entirely in your browser with no server-side processing.

They are utility and experimental low-stakes tools written predominantly by LLMs.

The colophon lists commit messages and transcripts for every tool.

Data & Text

  • JSON Formatter

    Format, validate, and minify JSON. Shareable via URL.

  • Word & Character Counter

    Count words and characters with multi-section support. Shareable via URL.

  • JSON Diff Tool

    Compare two JSON documents with Git-like diff visualization. Shareable via URL.

  • Lorem Ipsum Generator

    Generate placeholder text by words, characters, sentences, or paragraphs. Shareable via URL.

  • JSON to YAML

    Convert JSON to YAML in block, flow, and quoted styles. Shareable via URL.

  • YAML to JSON

    Convert YAML to JSON with pretty or compact output. Shareable via URL.

  • Base64 Encoder / Decoder

    Encode text to Base64 or decode Base64 back to text. Shareable via URL.

Networking

  • Subnet Calculator

    Visual subnet division and joining for IP address planning. Shareable via URL.

  • DNS Lookup

    Look up DNS records (A, AAAA, MX, TXT, and more) via Cloudflare DNS-over-HTTPS. Shareable via URL.

Image & Media

  • Color Picker

    Pick colors visually, convert between hex, RGB, and HSL, and sample colors from your screen or an image. Shareable via URL.

  • Media Metadata Viewer

    Preview photos and videos and inspect file, media, EXIF, and container metadata. Shareable via URL.

Development

  • JWT Decoder

    Decode and inspect JSON Web Tokens. Shareable via URL.

  • URL Decoder

    Decode and deconstruct URLs into protocol, domain, path, query parameters, and more. Shareable via URL.

  • Diagram Visualiser

    Render Graphviz DOT diagrams live with export to SVG and PNG. Shareable via URL.

  • Mermaid Diagram Visualiser

    Render Mermaid diagrams live with export to SVG and PNG. Shareable via URL.

  • URL Cleaner

    Remove common click-tracking parameters from URLs while preserving everything else. Shareable via URL.

Miscellaneous

  • Timezone Comparison

    Compare working hours across timezones to find a meeting slot. Shareable via URL.
